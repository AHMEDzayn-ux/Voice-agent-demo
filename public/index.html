How we measured
Streaming
Same 16 kHz mono audio at 1× speed in 20 ms chunks. G.711 clips were A-law round-tripped. The demo replays captured events.
Language
Nova-3 used Sinhala mode. Gemini used the si hint. First Sinhala is a script check.
Timing
Silero VAD estimated speech boundaries. First final can arrive before the caller finishes speaking.
Cleanup
CER and WER use a human-verified reference. The scores ignore formatting and punctuation. LLM delay comes from the captured Flash-Lite request.
